# Urban Infrastructure & Bike Transit Planning Sample

- **Source Language:** French (France) 🇫🇷
- **Target Language:** Portuguese (Brazil) 🇧🇷
- **Domain:** Urban Planning, Cycling Infrastructure & Public Transport (Grand Paris Express)
- **CAT Tool Used:** MateCat (PEMT - Post-Editing Machine Translation & Terminology Validation)

## About the Project
Technical translation and localization sample of urban transport network expansion and intermodality reports, focusing on cycling integration (*rabattement à vélo*) for the upcoming Clichy-Montfermeil station. The project required strict terminological rigor in urban zoning, metropolitan transit flows, and sustainable mobility infrastructure.

## Project Files
- `original_FR_urban_mobility.txt`: Original source text extracted from French urban planning documentation.
- `translation_PTBR_urban_mobility.txt`: Finalized technical translation, post-edited and validated in MateCat.
