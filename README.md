# Urban Infrastructure & Bike Transit Planning Sample

- **Source Language:** French (France) 🇫🇷
- **Target Language:** Portuguese (Brazil) 🇧🇷
- **Domain:** Urban Planning, Cycling Infrastructure & Public Transport (Grand Paris Express)
- **CAT Tool Used:** MateCat (PEMT - Post-Editing Machine Translation & Terminology Validation)

## Sobre o Projeto
Amostra de tradução técnica e localização de relatórios de expansão de redes de transporte urbano e intermodalidade, focando na integração cicloviária (*rabattement à vélo*) para a futura estação de Clichy-Montfermeil. O projeto exigiu rigor terminológico em zoneamento urbano, fluxos metropolitanos e infraestrutura de mobilidade sustentável.

## Arquivos do Projeto
- `original_FR.txt`: Texto original extraído de documentação de planeamento urbano francês.
- `translation_PTBR.txt`: Tradução técnica finalizada e revisada no MateCat.
